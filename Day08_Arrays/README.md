## 💡 Key Concepts Learned

### 🔹 Array Deletion

Learned how to delete all occurrences of a specific element by creating a new array with the required size.

### 🔹 Array Reversal

Used the **Two Pointer Approach** to reverse an array efficiently.

### 🔹 Merge Two Sorted Arrays

Used three pointers to merge two already sorted arrays into a single sorted array.

### 🔹 2D Array Traversal

Learned how to traverse rows and columns using nested loops.

### 🔹 Searching in 2D Array

Implemented element searching using row and column traversal.

### 🔹 Sum and Average

Calculated the sum and average of all elements present in a 2D array.

### 🔹 Diagonal Sum

Learned how to identify and calculate the sum of primary and secondary diagonal elements.
