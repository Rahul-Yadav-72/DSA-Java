# 📚 Day 07 - Arrays in Java

Welcome to **Day 07** of my **DSA in Java** journey.

This folder contains Java programs covering the fundamentals of arrays, searching algorithms, array manipulation, and subarray problems. The goal is to build a strong foundation for Data Structures & Algorithms and coding interviews.

---

## 🚀 Topics Covered

- Array Basics
- Linear Search
- Largest Number in an Array
- Binary Search
- Reverse an Array
- Pairs in an Array
- Subarrays
- Maximum Subarray Sum (Brute Force)
- Maximum Subarray Sum (Prefix Sum)

---

## 📂 Programs

| No. | Program | Description |
|:---:|---------|-------------|
| Q1 | Linear Search | Search an element using Linear Search |
| Q2 | Largest Number | Find the largest element in an array |
| Q3 | Binary Search | Search an element using Binary Search |
| Q4 | Reverse Array | Reverse an array using two pointers |
| Q5 | Pair Array | Print all possible pairs in an array |
| Q6 | SubArray | Print all possible subarrays |
| Q7 | Max SubArray | Maximum Subarray Sum using Brute Force (O(n³)) |
| Q8 | Max SubArray Prefix | Maximum Subarray Sum using Prefix Sum (O(n²)) |
